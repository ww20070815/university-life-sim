# 原创音频与授权说明

本目录四首 BGM 由本项目 scripts/compose-audio.py 的原创音符序列及数学合成音色生成，没有调用第三方音乐 API，没有使用采样包、流行歌曲、商业游戏或影视旋律、录音。

项目作者可以将这些生成音频随本游戏公开使用、修改和分发。生成脚本与乐谱一并保留，便于追溯与再制作；这不是对任何外部音乐的授权声明。

- campus.wav《校园午后》：76 BPM，校园及普通探索。
- library.wav《书页与阳光》：68 BPM，图书馆与学习。
- story.wav《晚风正好》：72 BPM，重要人物对话。
- graduation.wav《未完的夏天》：74 BPM，毕业。

它们是实际可播放的原创合成纯音乐，使用轻柔钢琴式敲击、拨弦式伴奏与淡弦乐近似音色，不是录音室真实钢琴或木吉他录音。每首约 50～56 秒、单声道 PCM WAV，浏览器原生解码。旋律和尾音按周期组织，循环点短平滑；硬件音色和循环听感仍需真机/耳机试听。

轻风使用 Web Audio 噪声经过低通滤波单独生成，默认关闭，可独立调节，不混进 BGM。八类短音效由 audio.js 生成并缓存，不依赖缺失文件；sfx/README.md 记录接口。

没有 Service Worker 缓存。BGM 仅用户启用后按需加载，最多两个 Audio 通道交叉淡化。未来可以用统一风格的正式乐器演奏替换同名资源，届时需保留明确授权并更新素材说明。
