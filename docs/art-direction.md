# 原创美术制作记录

使用内置 imagegen 生成，非 CLI，无收费 API 依赖。两位角色都是原创成年中国大学生，现代普通校园穿搭，自然比例；六个场景以当代中国大学生活为参考，用统一的光线、奶油白、青绿、浅金和天空蓝连接。

人物图集每张三列两行：平静、开心、疲惫、沮丧、闭眼、学士服。生成图片带透明通道，使用整幅 WebP 图集切换格子；保留整体像素比例，不拉伸人物。轻微呼吸和闭眼帧用于轻量待机。不同表情的姿态存在生成误差，未来可由原画师精修对齐。

素材由 scripts/prepare-assets.py 进行 WebP 压缩（不重绘）。以下保留实际提交的生成提示词，便于以后延续美术风格。
