# V3.4 可探索校园世界实施与验收计划

仅本地 v3-development；保留V3.1/V3.2/V3.3备份及工作区，不提交、推送、发布或删除真实存档。

## 审计和架构

game.js核心规则段保持原样，新增地点行动只桥接原takeAction UI入口。relationships.js仍为唯一扩展写入者，继续使用runId、核心签名、双锚点及读取失败禁止写入。phone/story不重写。

新增 campus-data.js（十地点、NPC排期、30微事件）、campus.js（纯逻辑与校验）、campus-art.js（代码原生SVG校园）、campus-ui.js（地图/地点/记录）。无需外部地图API、图片生成、后端或构建。现有真实背景按相对路径复用，不造不存在的资源。

## 九阶段顺序

1. 检查分支、核心/扩展/表现层与原100组基线，保留V3.3快照。
2. 定义十地点ID、介绍、主题、背景、活动、NPC规则、原storyId关联、开放条件与事件数据。
3. 建立统一校园俯视插画：道路、草地、建筑、湖泊、树木与十个实际可点区域；电脑地图加详情。
4. 手机使用独立纵向校园布局和纵向详情，不缩小桌面图；安全区、触控与返回。
5. 六人按学年/学期/回合、相识、关系、剧情和原事件确定排期，同状态不因重进而随机变化；总可通过地图找到。
6. 每学年8回合按秋/冬/春/夏映射；总结仍属于刚结束学期，天气稳定推导，仅影响视觉和文字。
7. 三十个原创地点微事件，各两种独立选择/结果；只记录体验，无数值奖励，不改原18事件队列。已开始可稍后续读，毕业可回顾季节事件。
8. 地点跳转既有人物档案、聊天和原story；不绕过相识、章节、恋爱或全局奖励预算。手机地图入口与记录连接真实状态。
9. campus命名空间、安全恢复和全回归；候选快照与报告。

## 存档
