## 3. 可播放音频与技术

| 配乐 | 用途 | BPM | 长度 |
| --- | --- | --- | --- |
| 校园午后 campus.wav | 首页/普通校园 | 76 | 50.53 秒 |
| 书页与阳光 library.wav | 图书馆/学习 | 68 | 56.47 秒 |
| 晚风正好 story.wav | 实际重要人物互动结果 | 72 | 53.33 秒 |
| 未完的夏天 graduation.wav | 毕业回顾 | 74 | 51.89 秒 |

均是 scripts/compose-audio.py 依据本项目原创音符序列合成的实际 PCM WAV，不是不存在的路径。钢琴式敲击、拨弦式伴奏和淡弦乐均为数学合成近似音色，没有外部采样、歌曲、影视或商业游戏素材。不是录音室真实钢琴/木吉他演奏。四首合计约 9 MiB，按需加载，不预取全套；详细元数据见 assets/audio/catalog.json，来源说明见 assets/audio/README.md。

两个复用 HTMLAudioElement，最多两条 BGM 在 1.5 秒切换期间同时运行；HTTP 预览经同一个 AudioContext 的 GainNode 控制音量与淡化。file:// 下不将本地媒体接入 MediaElementSource，避免不透明来源导致静音；能力不足时也回退原生元素音量。正常同曲不调用 play 重播、不重置时间；快速返回旧曲也会完成另一通道的淡出。实际 WAV 周期组织尾音并对接点短平滑，听感仍需耳机和真机评价，文件模式仍需人工验证。

短音效：按钮、选项确认、属性增加、属性减少、新消息、关系里程碑/成就、学期结束、毕业完成。缓存在 AudioBuffer，最多四个短声。普通按钮与真实结算分别触发，禁用按钮没有成功音；相同结算 token 去重。属性结算以一条合并提示表达增减，不逐属性密集响。

新相识与关系阶段变化使用消息/里程碑提示。完整手机消息与成就系统尚不存在，相关音效可在设置中试听，业务接口预留给 V3.2/V3.6，不伪造消息或成就解锁。轻风为低通合成噪声，独立开关/音量，默认关闭，不混入 BGM。

默认音乐/音效/轻风都关闭，音量预设 35%/65%/15%。用户主动开启后才播放；刷新只恢复偏好，仍等待交互。后台、pagehide、音频系统中断会暂停；恢复前台等待新的用户手势。全部静音立即暂停音乐、停止短声和轻风；加载/策略拒绝被捕获，不进入游戏异常路径。

## 4. 存档兼容与局次绑定

| 键 | 作用 |
| --- | --- |
| university-four-years-v1 | 原核心档，版本仍是 1，结构不变 |
| university-four-years-visual-v2 | 原外观与动画设置，不变 |
| university-four-years-v3 | 人物扩展，含独立 runId、核心快照签名与关系记录 |
| university-four-years-v3-previous | 用户明确重建时尽量保留的上一份扩展，非完整档案库 |
| university-four-years-audio-v3 | 独立声音偏好，不改游戏或关系 |

初次读取 V1/V2 不写核心，也不立即创建扩展。只有真实互动、主要行动保存或明确新游戏时持久化扩展。核心保存使用前后双锚点，兼容两个键间写入中断；不匹配的局次和损坏扩展只隔离，不删除旧核心。重建需要页面内明确确认，并尽量备份上一份扩展。

新局显式生成新 runId 和初始关系，不能继承上一局已领取次数；角色、动画和声音偏好保留。禁止存储时本页仍可体验关系，明确提示无法持久保存；刷新无法保存的变化会丢失。JSON 导出/导入尚未实现，规划到 V3.6，不应把当前独立扩展误认为跨设备同步。
