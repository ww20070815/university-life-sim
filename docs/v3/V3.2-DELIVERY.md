日期：2026-11-11。分支 `v3-development`。功能代码与自动回归已完成；**浏览器视觉、手机真机验收未完成**。没有开始 V3.3，没有提交/推送或发布 GitHub Pages，没有删除或操作真实浏览器存档，没有重制 V2 美术。

## 实际功能与入口

进入原游戏，点击“校园手机”。首页显示学年、学期、回合、未读数和四个应用。事件待选、学期总结及毕业弹窗中也有手机入口，返回后恢复原有阶段，不额外推进回合。

1. **聊天**：六位人物独立联系人和消息记录，未相识者锁定。认识后开放专属问候和第一组日常，第二组按学期和已有主要行动解锁。每人两组、每组三个方向，共 12 组情境、36 个分支回应/选择标记。普通回复免费；指定关系回复调用原 V3.1 +4/+5/+6 互动索引并占用全体人物共享的一次交流。已经选择的情境不能重复回答。事件、总结或毕业阶段禁止关系收益，仍可普通回复和回看。周老师仅师生指导，没有恋爱。
2. **校园动态**：24 条原创内容，每名 NPC 四条，分别在第 1/3/5/8 学期开放。覆盖学习、宿舍、社团、摄影、竞赛、运动、考试、实习和毕业。大一不会显示毕业动态。详情点击标记已读，无属性或关系收益。
3. **通知中心**：学业、竞赛、社团、人物、学期、实习与就业六分类，支持筛选、已读、详情与相关聊天/任务/动态跳转。唯一 ID 区分每次实际事件，刷新不会重复生成；保留通知历史。
4. **任务**：13 项任务覆盖日常、人物、学业、竞赛、社团、学期六类。每项定义 ID、说明、类型、结构化开放条件、目标与真实行为来源，保存进度/状态/完成回合及相关 NPC。可筛选进行中、已完成或类型。没有领取进度或额外数值奖励按钮。

六位 NPC：林知夏、沈砚、程乐、许南乔、顾清禾、周老师。六人均无新增立绘，`portrait:null` 保持不变；复用姓名印记，预留的立绘接口支持未来图片加载失败回退。现有男女主及六场景素材没有修改。

## 架构与存档

不新增存储键。核心仍为 `university-four-years-v1`、版本 1，原数据结构不扩充。人物扩展仍为 `university-four-years-v3`，原 `schema:1`、`data.version:1`、runId、人物、互动和预算字段保留；增加可选的 `data.phone`：

```text
phone.schemaVersion: 1
phone.runId: 与扩展 runId 相同
phone.messages: 消息 ID、NPC、回合、已读状态
phone.replies: 情境 ID → 所选方向、回合
phone.flags: 选择标记
phone.feedRead: 已读动态 ID
phone.notifications: 通知 ID、回合、已读状态
phone.tasks: 任务 ID → 进度、状态、完成回合
phone.triggered: 已触发的消息/通知事件 ID
```

正文、身份、分类、跳转目标从版本化本地数据解释，存档不含可执行函数。界面使用 textContent，不解释存档 HTML。schema 校验覆盖 ID、唯一性、长度、枚举、关系回复对应的原互动、标记一致性、runId、未来回合/动态、通知与真实核心记录的匹配。

### 初始化、保存和冲突

- 旧 V1/V2/V3.1 无 phone：加载时仅在内存补齐，根据已有真实记录派生任务与消息；读取和渲染不写盘，不重置原人物。下一次实际保存、回复或已读操作才落盘。
- 所有手机写入均走既有关系 store，与人物共享一次快照同步、冲突检查及持久化；未另建一套会互相覆盖的 localStorage 系统。
- 普通回复仅修改 phone。关系回复先检查聊天资格和 V3.1 预算，再执行同一 `interact`，一次写入关系和回复记录。失败不会先记回复或先扣次数。
- 每个消息/通知有幂等 token。任务从核心 counts、完成的事件日志、关系互动和保存的回复派生，渲染/点击任务卡/反复刷新不会增加进度。
- 核心保存仍先写前后双锚点，写核心成功后再更新手机并收敛扩展。核心写入失败不会生成未来手机记录；最后扩展保存失败时，刷新从已保存核心幂等补齐。
- 损坏或错局扩展保留原文并隔离，原核心仍可继续；不静默删除 phone 来冒充修复。明确重建会重置人物及手机，并尽量备份旧扩展，界面有覆盖说明。
- 新游戏明确换 runId，清空回复、标记、已读及旧任务；根据新局真实状态生成初始内容。切换男女主只改外观设置，不改手机。
- 过期页面发现另一页已推进、换局、清除或修改扩展时拒绝覆盖；同局顺序操作会先合并最新选择和已读。localStorage 不是跨进程事务，本轮不宣称覆盖所有极端同时落盘时序。
- 存储禁用或额度不足：游戏和手机本页可体验，提示不能持久保存；重复回复仍被本页状态拒绝。部分手机脚本加载失败时入口提示不可用，原游戏仍能继续。

## 消息触发与表现

暖白、浅绿、米色与深绿文字；二列应用卡、消息气泡、纸笺动态、任务进度条。导航在正常文档流中，不固定覆盖回复按钮。沿用原安全区、弹窗滚动与减少动画规则；聊天历史有独立可滚动区域。上述是实际 CSS 实现说明，**不是浏览器布局测试通过声明**。
