## 架构与约束

原 game.js 规则段保留，V1/V2 核心对象与判定函数不扩充字段。新增数据层通过普通脚本 UMD 模块加载，继续支持 file:// 与静态 Pages；纯逻辑可直接 require 测试。

- npc-data.js：六名虚构人物、成年身份、初始关系、偏好、背景及五章剧情设计资料。
- relationships.js：关系值/阶段、每回合一次的全局互动预算、重要选择、相识记录、独立扩展存储。
- 后续 story-engine.js / campus-phone.js / campus-map.js / majors.js / memories.js：按里程碑引入，不提前挂空入口。
- audio.js：独立表现层控制器、原生 Audio 双通道淡化、Web Audio 短音效/可选轻风；所有设置独立保存。

扩展状态使用 university-four-years-v3，与 V1 核心进度签名和独立 runId 绑定。核心保存时先写可恢复的双锚点记录，再保存核心，最后收敛锚点；刷新可识别写入中断。发现不同局或坏扩展时保留原数据、隔离奖励，不删除核心档。明确确认后才重建当前局扩展。新游戏显式换 runId、重置关系，外观和音频偏好保留。

V3.1 的关系互动仅在“可行动”阶段开放，全体 NPC 每回合合计一次，可完全不互动通关。只改独立关系值，不增加原五项属性或金钱，不推进回合。普通查阅免费且不写收益。

## 稳定版本与回滚

每完成一个里程碑，先跑测试、留验收记录，再压缩源码/素材/测试到 backups/，不包含 .git。回滚前另存当前工作区；将对应快照解压到单独目录检查后再还原目标源码，不使用 git reset --hard，不删浏览器存储。V2 回滚只是不读取 V3 扩展；原核心档仍是版本 1。发布需用户另行明确授权；最终仍使用同一仓库、相对资源路径和原 Pages 网址。
