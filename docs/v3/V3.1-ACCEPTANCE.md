## 实际已实现的功能

- 六份独立人物资料：性格、成年身份、背景、常见地点、成长方向、相识对白；各有三种主题与不同回应。
- 六人各自的关系值、是否认识、相识记录、互动选择及回合历史。关系严格限定 0～100；五个阶段为陌生（0～19）、认识（20～39）、朋友（40～59）、亲密好友（60～79）、深厚羁绊（80～100）。
- 交流、倾听、合作三类互动，基础收益分别为 +4/+5/+6，接近 100 时取实际剩余空间。合作需要已经执行过对应的原主要行动。
- 全体人物共享每回合一次的关系收益，仅行动阶段开放；浏览不消耗回合，事件待选、学期总结、毕业阶段不领取奖励。毕业后可只读回看。
- 独立人物扩展存档，刷新恢复、新游戏重置、换主角保留关系；坏档和不同进度扩展隔离，不自动删除原数据。明确确认后才重建，尽量备份旧扩展。
- 复用 V2 主角、表情、场景、七行动、五属性和金钱、18 个校园事件、学期总结、手记、八种基础结局和自动存档。原有声音模块及设置也进行了回归。

## 发现并修复

1. **多页面关系覆盖。** 修复前，两个页面载入同一回合后，各自都能成功互动；后保存者覆盖先前人物奖励。现在每次互动和核心保存前读取最新扩展，同局合并已领取的预算和人物记录，后续重复交流会被拒绝。
2. **过期页面覆盖新档。** 增加核心快照、已有局次与存档是否被清除的检查。另一页面已推进或换局时，旧页面不能写回覆盖，显示刷新提示。已损坏的核心 JSON 不再被当作“存储被禁用”而继续写关系。冲突页面不提供重建入口，底层重建也检查核心进度，避免确认过程中进度变化。
3. **收益预告不准确。** 原按钮在关系 97 时仍显示 +4/+5/+6，现在均显示实际 +3；100 时显示“关系已满”。没有改变数值或每回合预算。
4. **补充异常数据边界。** 学期总结、毕业时不允许出现尚未开放的下一回合奖励记录；异常扩展保留原文并隔离。正常旧档和双锚点中断恢复规则保留。

这些修改只涉及人物存储保护和界面提示；`game.js` 在界面初始化之前的原核心规则源码与 V1 测试基准逐字相同。

- 原有八种结局均通过真实 32 回合路线达成，未直接改毕业属性来冒充通关。优先级和触发阈值保持原样。

## 原有存档兼容情况

- 核心键仍为 `university-four-years-v1`，版本仍为 1；没有增删核心字段或删除玩家进度。
- 人物扩展仍用 `university-four-years-v3`，外观和声音设置各自独立；本轮没有改键或进行迁移。
- 真实 V1 测试基准生成的行动、事件待选、学期总结、毕业四种存档均可在带 V3 模块的界面读取，原字符串保持不变；V2 使用同一核心结构。
- 有扩展时换主角、刷新不重置关系；明确新游戏时换 runId、重置六人和预算；毕业只读。
- 坏扩展、不匹配扩展保留并隔离；旧核心继续可保存，不通过删除旧档解决问题。存储被禁用时允许本页临时体验并提示无法持久保存。
- `localStorage` 不是多页面事务数据库。本轮覆盖顺序的多页面写入及过期页保护；没有宣称覆盖所有浏览器进程真正同时落盘的极端时序，建议同一局使用一个活动页面。

8. 既有音频回归仍需手机实际试听、解码、后台和来电中断验证。本轮未用桌面测试代替真机听感或 Safari 自动播放验证。
