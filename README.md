# 大学四年：青春没有标准答案 · V2.0

原创现代中国校园人生模拟游戏。原生 HTML、CSS、JavaScript，无框架、无构建、无登录。V2 在 V1 原有玩法上升级视觉和交互，**数值规则保持不变**。

## 立即启动

Windows 双击项目根目录 `index.html`，可用较新的 Chrome 或 Edge 打开。所有美术资源都在本地，不依赖 CDN。PWA 功能需通过 HTTPS 网站访问，直接打开文件仍可运行游戏。

本地手机预览：

```powershell
node preview.cjs
```

电脑访问终端显示的 `http://localhost:8080/university-life-sim/`；手机、平板与电脑连接同一 Wi-Fi，在浏览器中输入终端输出的局域网地址。不要在手机输入 localhost。防火墙需允许 Node.js 在当前私人网络接受连接；电脑需保持开机。按 Ctrl+C 停止服务。游戏本身不依赖 Node.js，它只用于可选预览和自动测试。

## V2 新增体验

- 电影海报式首页：现代校园背景、原创男女主、开始、继续、入学指南。
- 两位成年中国大学生主角：男主深蓝外套、白色内搭；女主青绿针织衫、米白衬衫、高马尾。选择仅影响外观，可在成长档案中更换。
- 每人一张透明 WebP 表情图集：平静、开心、疲惫、沮丧、闭眼帧、学士服。健康低于 35 显示疲惫，心情低于 35 或负面结果显示沮丧；心情至少 80 或正面反馈显示开心；其他情况平静。
- 六幅统一光线与配色的原创场景：校园主广场、图书馆、上床下桌宿舍、操场、食堂、毕业礼堂。学习/技能/兼职进入图书馆，社交进入广场，运动进入操场，娱乐/休息进入宿舍。剧情按事件使用相应背景。
- 呼吸与眨眼、人物点击回应、属性数字强调、真实增减浮动提示、背景交叉淡入、事件结果页、学期回顾、毕业学士服与轻量星光。
- 桌面三列布局；手机依次显示场景、档案、行动、日志。弹窗可滚动、核心触控按钮至少 44px，适配安全区、横屏、平板与减少动画偏好。
- 顶部可关闭动画。系统 `prefers-reduced-motion` 优先，切到后台暂停人物主体动画。

图片为内置 imagegen 生成的原创半写实插画，非商业素材拼贴。生成提示词保存在 `docs/art-direction.md`。人物不同表情的细节、姿势仍有少量生成差异，待机是轻量图集动画，尚未制作独立头发骨骼或完整骨骼动画。没有把几何占位图作为完成的主角立绘。

## V1 原有玩法完整保留

4 学年 × 2 学期 × 4 回合 = **32 回合**。每回合选择一次主要行动，然后处理校园事件；事件完成后回合才加 1。每 4 回合查看一次学期总结，最后进入毕业。

初始数值：学业 45、专业技能 20、社交 40、健康 75、心情 70、金钱 1000 元。五项属性限制在 0～100，金钱限制在 0～999999 元。

| 主要行动 | 原有数值效果 |
| --- | --- |
| 认真学习 | 学业 +9，技能 +1，健康 -3，心情 -4 |
| 技能训练 | 技能 +10，学业 +1，健康 -4，心情 -3 |
| 社交活动 | 社交 +10，心情 +5，金钱 -120，健康 -2 |
| 校园兼职 | 金钱 +360，社交 +2，健康 -7，心情 -6 |
| 健身运动 | 健康 +13，心情 +6 |
| 娱乐放松 | 心情 +15，学业 -3，金钱 -60 |
| 好好休息 | 健康 +11，心情 +9 |

余额不足不能执行付费行动或付费事件选项。没有额外的固定生活费扣款。每个事件都有免费出口，动画不参与数值结算。

原有 18 个事件全部保留：室友游戏、高数复习、偶遇同学、兼职机会、社团招新、食堂意外、宿舍矛盾、运动会、编程比赛、老师项目、奖学金、期末考试、实习申请、秋招、毕业选择、突如其来的雨、校园集市、晚风校园。原有年级、属性条件及固定事件时机没有改变。大三第一回合固定实习、大四第一回合固定秋招；学期期末固定考试，最后一回合由毕业选择替代。

### 毕业判定优先级（从上到下匹配）

| 结局 | 原有条件 |
| --- | --- |

| 六边形战士 | 五项属性全部 ≥ 75 |
| 保研成功 | 学业 ≥ 90、技能 ≥ 60、健康 ≥ 40 |

| 兼职达人 | 主要行动的兼职次数 ≥ 8、金钱 ≥ 3000、健康 ≥ 30 |
| 快乐毕业生 | 未匹配上述条件，此时学业 ≥ 40、健康 ≥ 20 |

## 存档安全

- **原键名 `university-four-years-v1` 和版本号 1 完全保留**，没有迁移或重命名。
- 页面初始化只读取原档，补选人物不写游戏档、不更改属性与行动次数；原有事件、学期总结和毕业状态可恢复。
- 外观单独保存到 `university-four-years-visual-v2`，其中只有角色与动画开关。
- 旧档无法解析时保留原始字符串，不在初始化时覆盖。浏览器禁止存储时显示提示，仍可在当前页面游玩。
- 每次有效行动、事件结算和学期继续立即保存，事件结果动画不阻塞存档。刷新时结果页可能直接进入下一阶段，因为结果已经结算保存；不会重复发放奖励。
- 当前为单存档。只有明确确认“新游戏”或“清除存档”才替换/删除本局记录。清除游戏档不会删除外观设置。
- 网站存档只保存在当前浏览器本机。换手机、换浏览器、文件网址与 HTTP 网址、无痕模式之间不共享存档。

## PWA / 添加到主屏幕

已添加相对路径 Manifest、192/512px 桌面图标、180px Apple Touch 图标、主题色、`standalone`、相对 `start_url` 与 `scope`，适配原 GitHub Pages 子路径。

本次**不注册 Service Worker，也不承诺托管网站离线缓存**，因此不会因新 SW 缓存锁住 V2，也不操作旧存档。在线首次加载仍需要网络。直接下载整份项目到 Windows 后可离线打开。

iPhone/iPad 在 Safari 打开 HTTPS 网站后，通过分享菜单选择“添加到主屏幕”；安卓通过浏览器菜单查找“添加到主屏幕”或“安装”。入口名称和独立窗口支持取决于浏览器，尚需真机验证；不保证所有国产浏览器都提供安装入口。

## 文件结构与学习顺序

```text
index.html                    首页、游戏区、人物舞台和弹窗容器
style.css                     设计变量、布局、图集动画、响应式规则
visual.js                     角色设置、表情判断、场景映射；只读游戏状态
 game.js                      原有规则 + V2 页面交互（根目录文件）
manifest.webmanifest          主屏幕启动配置
assets/characters/*.webp       两位主角图集
assets/backgrounds/*.webp      六个背景
assets/backgrounds/fallback.svg  场景加载失败的简化后备图
assets/icons/                 原创书页图标
preview.cjs                   只提供静态文件的预览服务
scripts/prepare-assets.py     素材压缩与图标生成，运行游戏不需要
 tests/                       核心、V1兼容、存档边界测试与V1对照源码
 docs/                        美术提示词、验收与发布说明、浏览器截图
backups/                      本地V1压缩备份（Git忽略）
```

初学者建议先读三条线：

1. 对象和数组：`freshState`、`ACTIONS`、`EVENTS`、`ENDINGS` 如何描述游戏数据。
2. 函数与状态：`takeAction → chooseOption → continueTerm → judgeEnding`。阶段锁保证一回合只有一次主要行动，`applyEffects` 统一限制属性范围。
3. DOM、事件与存储：`render` 更新界面、按钮回调提交选择、`save` 保存；`visual.js` 的 `paint` 只读状态，角色设置使用独立存储键。

小练习：先在 `visual.js` 修改某个行动的场景映射，观察画面改变但数值不变；再读 `moodFor` 的条件顺序。先练表现层，避免无意改变平衡。
