# 大学四年：青春没有标准答案

这是第一阶段的完整可玩版：4 个学年 × 2 个学期 × 4 次行动 = **32 回合**。全中文、原生 HTML/CSS/JavaScript，无第三方运行依赖，无登录、数据库、付费接口或网络请求。

## 先玩起来

### Windows：直接打开

1. 打开 `D:\大学生生存模拟器` 文件夹。
2. 双击 `index.html`，或右键选择用 Edge / Chrome 打开。
3. 选择主要行动，再完成校园事件的选择。每 4 回合会弹出学期总结。
4. 第 32 回合之后，先查看最后的学期总结，再点击“拆开我的毕业信”。

游戏不需要安装 Node.js。保持 `index.html`、`style.css`、`game.js` 在同一个文件夹即可，断网也能玩。推荐较新的 Edge、Chrome 或 iPhone Safari。

### iPhone：同一网络访问

iPhone 的“文件”预览并不等于 Safari 网页运行环境。可用附带的静态预览工具：

1. 电脑安装了 Node.js 的情况下，在当前文件夹打开 PowerShell。
2. 输入 `node preview.cjs`。
3. 电脑浏览器访问 `http://localhost:8080`。
4. 手机与电脑连接同一 Wi-Fi，在 Safari 中输入终端输出的手机地址，例如 `http://电脑的局域网IP:8080`。不要在手机输入 localhost。
5. 如果无法访问，检查 Wi-Fi 是否隔离设备、电脑是否休眠，以及 Windows 防火墙是否允许 Node.js 在当前私人网络接收连接。
6. 玩完后在终端按 Ctrl+C 停止预览。

`preview.cjs` 只发送三个静态网页文件，没有游戏后端逻辑，也不上传存档。如果端口 8080 被占用，先关闭其他占用该端口的服务。

## 当前玩法

- 五项 0～100 的属性：学业 45、技能 20、社交 40、健康 75、心情 70；初始余额 1000 元。
- 七种行动，每个按钮列出全部收益与代价。社交需要 120 元，娱乐需要 60 元；余额不足就不能选择。
- 没有固定生活费扣除，可以通过校园兼职、兼职事件、奖学金补充余额。金钱范围为 0～999999 元。
- 每次行动后有一个校园事件，共 18 个不同事件，每个有 2～3 个选项。付费选项检查余额，所有事件都有免费出口。
- 大一、大二有高数和社团事件；编程比赛需要大二及技能 30；老师项目需要大二及学业 55；奖学金需要大二及学业 65。
- 实习最早大三出现，大三第一个回合固定出现一次；秋招仅大四出现，大四第一个回合固定出现一次。
- 每学期期末固定考试；最后一学期期末由“毕业前的选择”替代。
- 校园手记记录实际变化：例如学业到达 100 后，额外学习不会继续突破上限。
- 8 次学期总结记录六项数值及与学期初的差值。毕业页面包含专属故事、最终数值、行动统计和重新开始按钮。
- 游戏内“玩法与毕业方向”可以查看结局规则。

### 结局优先级

从上到下匹配，满足第一条后就确定结局。“延毕危机”是保护性检查，优先于能力结局；“六边形战士”优先于其他优秀路线。

| 顺序 | 结局 | 条件 |
| --- | --- | --- |
| 1 | 延毕危机 | 学业 < 40 或健康 < 20 |
| 2 | 六边形战士 | 五项属性全部 ≥ 75 |
| 3 | 保研成功 | 学业 ≥ 90，技能 ≥ 60，健康 ≥ 40 |
| 4 | 大厂工程师 | 技能 ≥ 90，学业 ≥ 65，健康 ≥ 40 |
| 5 | 创业青年 | 技能 ≥ 70，社交 ≥ 75，金钱 ≥ 2000 |
| 6 | 校园人气王 | 社交 ≥ 90，心情 ≥ 60 |
| 7 | 兼职达人 | 校园兼职行动 ≥ 8 次，金钱 ≥ 3000，健康 ≥ 30 |
| 8 | 快乐毕业生 | 未匹配前面的条件；此时学业 ≥ 40、健康 ≥ 20 |

事件里的兼职不算主要行动的兼职次数。不同路线可能同时满足多个条件，因此最终名称也取决于优先级。测试确认这八种结局都有完整 32 回合的可达路线。

## 存档说明

使用 `localStorage`，键名为 `university-four-years-v1`。每次行动、事件选择、学期继续及新游戏都会保存；刷新时自动恢复。事件已抽取后也会保存，刷新不会重新抽事件或重复发放主要行动收益。

完成游戏后会保存该局结局。可以查看四年手记，再通过“点击查看毕业结局”重新打开。当前是**单存档**：新游戏会替换上一局和结局，没有跨局收藏册。

旧版本、异常 JSON、属性越界、回合与行动次数不一致等数据会被安全拒绝并重新开局。浏览器禁止存储时游戏仍可运行，但会显示“本次进度仅保留在当前页面”。清除存档和新游戏都有页面内确认。

存档属于当前浏览器和网址：双击文件、localhost、127.0.0.1、手机地址之间不共享进度；移动项目文件或更换浏览器也可能使原有文件网址存档不可见。Safari 无痕模式或清理网站数据会影响存档，不支持电脑与手机自动同步。

## 初学者先读这三个知识点

### 1. 对象和数组：用数据描述游戏

`freshState()` 返回一个状态对象。`stats` 保存属性，`turn` 保存已完成的回合数，`counts` 保存各行动的次数。

`ACTIONS` 是行动数组，`EVENTS` 是事件数组，`ENDINGS` 是结局数组。新增普通事件时，通常只需在 `EVENTS` 添加一项，而不用重写事件弹窗。

小练习：把认真学习的学业收益从 9 改为 8，刷新后检查按钮说明和实际收益是否一起变化。

### 2. 函数、条件与状态：一次只处理一件事

重点顺序：`takeAction()` → `chooseEvent()` → `chooseOption()` → `continueTerm()` → `judgeEnding()`。

```text
action（可行动）
  → event（必须处理事件）
  → action（进入下一回合）
  或 summary（每4回合一次）
      → action（下一学期）
      或 ending（第32回合完成）
```

`takeAction()` 首先检查阶段与余额，随后立即改成 `event`。再点一次时，检查就不通过。界面禁用按钮是一层保护，逻辑中的条件检查是另一层保护。

`applyEffects()` 是统一的数值入口，通过 `Math.max()` 和 `Math.min()` 限制范围。实际只在事件选择完成后让 `turn` 加 1，所以总回合容易准确控制。

小练习：阅读 `chooseOption()` 中 `s.turn % 4 === 0`，理解取余运算为什么能检测学期结束。

### 3. DOM 事件与 JSON 存储：把规则连到网页

`addEventListener('click', ...)` 把按钮与函数连起来；`render()` 把状态显示到网页；`JSON.stringify()` 把对象转成文本存入 `localStorage`；`JSON.parse()` 把文本读回来；`validateSave()` 检查外部数据是否安全可用。

存档中的文字用 `textContent` 显示，避免把文字当 HTML 执行。

小练习：在普通行动后刷新，再在事件选择前刷新，观察两种阶段如何恢复。

## 验证结果与复测

### 已实际执行

```powershell
node --check game.js
node --test tests/game.test.cjs
```

自动测试共 8 组，涵盖：初始属性与边界、余额检查、事件免费出口和年级条件、固定事件时机、1000 局随机完整流程、结局阈值及优先级、无效存档、八种结局的完整行动路线。随机数采用固定种子，结果可重复。核心测试逐步验证存档往返及防重复提交。

真实 Windows Edge 通过静态预览进行了完整 32 回合试玩，查看了最后学期总结与六边形战士结局；事件弹窗刷新后恢复，毕业结局刷新后恢复；试玩检查未发现 JavaScript 控制台错误。新游戏、清除存档及指南按钮也进行了实际交互验证。

检查过桌面页面与窄屏毕业弹窗；窄屏观测到页面可视宽度和内容宽度同为 375px，没有横向溢出。**这不等于 iPhone 真机 Safari 验收。** 当前浏览器自动化工具仅允许 HTTP/HTTPS，因此未自动验证 `file://` 双击打开；代码使用传统脚本、相对样式链接，无模块导入、fetch 或 CDN，下面提供手动复测方法。

### 建议手动复测

1. Windows 双击 `index.html`，确认五项初始属性和 1000 元余额；断网后再打开，确认无需外部资源。
2. 选择学习，连续快速点击，确认只记录一次主要行动；事件选择后才进入下一回合。
3. 在事件未选择时刷新，确认同一事件、同一属性仍在；选完后刷新，确认已进入下一回合。
4. 消费至余额不足 120 元时，社交按钮应禁用；不足 60 元时娱乐也禁用，免费休息仍能使用。
5. 每 4 回合查看一次总结；第 32 回合处理毕业事件后只能查看总结和结局，不能继续第 33 回合。
6. 点击新游戏与清除存档，分别测试“保留当前旅程”和确认按钮。
7. 在 iPhone Safari 访问预览地址，竖屏与横屏切换，检查行动按钮、事件选项、长日志、毕业弹窗的文字与滚动是否正常。
8. 手机完成一次行动后关闭标签再打开同一地址，验证该设备自己的存档。

自动规则测试通过不代表游戏数值已达到最终平衡；欢迎实际试玩，记录某些路线是否过轻松或过困难。
